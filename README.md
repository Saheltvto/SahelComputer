# ساحل — فناوری اطلاعات و حسابداری هوشمند

وب‌سایت شرکتی ساحل، با ساختاری ساده و قابل گسترش برای انتشار روی GitHub Pages.

## ساختار پروژه

```
sahel-site/
├── index.html       صفحه اصلی (معرفی و خدمات)
├── login.html       صفحه ورود کاربر
├── dashboard.html    داشبورد مدیریت پروژه‌ها و شیت‌ها
├── css/
│   └── style.css    همه استایل‌ها (رنگ‌ها به‌صورت متغیر CSS در ابتدای فایل)
├── js/
│   ├── main.js       رفتار منوی موبایل صفحه اصلی
│   └── dashboard.js  رفتار منوی کناری داشبورد در موبایل
└── assets/           تصاویر و فایل‌های آینده (لوگو، آیکون‌ها و ...)
```

### وضعیت فعلی داشبورد

`login.html` و `dashboard.html` در حال حاضر **فقط نمای بصری (UI استاتیک)** هستند — با داده‌های نمونه، بدون اتصال واقعی به سرور یا احراز هویت. هر پروژه در داشبورد یک برچسب «مسئول پروژه» دارد که جای آن برای اتصال بعدی به Google Sheets/Apps Script (تعیین اینکه هر کاربر مسئول کدام پروژه است) از هم‌اکنون در طراحی در نظر گرفته شده.

## راه‌اندازی روی GitHub Pages

1. یک ریپازیتوری جدید در گیت‌هاب بسازید (مثلاً `sahel-site`).
2. محتوای این پوشه را در ریشه (root) همان ریپازیتوری قرار دهید و push کنید.
3. در تنظیمات ریپازیتوری، بخش **Settings → Pages** را باز کنید.
4. در قسمت Source، شاخه (branch) اصلی (`main`) و پوشه `/root` را انتخاب کنید.
5. بعد از چند دقیقه، سایت روی آدرسی شبیه `https://username.github.io/sahel-site` در دسترس خواهد بود.

## افزودن صفحات جدید

برای گسترش سایت، فایل‌های HTML جدید (مثلاً `services.html` یا `about.html`) را در کنار `index.html` اضافه کنید و در نوار ناوبری (`.nav-links` در `index.html`) لینک بدهید. استایل‌ها و اسکریپت مشترک از همان `css/style.css` و `js/main.js` استفاده می‌کنند.

## مراحل بعدی برنامه‌ریزی‌شده

- اتصال به Google Sheets برای ثبت و خواندن داده‌های مالی
- استفاده از Google Apps Script برای افزودن پروژه و کاربر
- ساخت پنل مدیریت مالی و تنخواه
